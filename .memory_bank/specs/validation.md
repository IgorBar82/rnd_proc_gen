# Validation Specification

## Параметры генерации процессов

### Общие параметры
| Параметр | Тип | Диапазон | Описание |
|----------|-----|----------|----------|
| `T` | float | `0 < T <= 10` | Время окончания процесса |
| `N` | int | `100 <= N <= 5000` | Количество шагов дискретизации |
| `X0` | float | `-5 <= X0 <= 5` | Начальное значение процесса |

### Параметры для Ornstein–Uhlenbeck
| Параметр | Тип | Диапазон | Описание |
|----------|-----|----------|----------|
| `theta` | float | `0 < theta <= 10` | Скорость возврата к среднему |
| `mu` | float | `-5 <= mu <= 5` | Долгосрочное среднее |
| `sigma` | float | `0 < sigma <= 5` | Волатильность |

## Формат запроса API

### `POST /api/v1/generate`

```json
{
  "process_type": "wiener | ou",
  "T": 1.0,
  "N": 500,
  "X0": 0.0,
  "theta": 1.0,
  "mu": 0.0,
  "sigma": 1.0
}
```

- `process_type`: строка, обязательное значение `wiener` или `ou`.
- Для `wiener` требуются только `T`, `N`, `X0`.
- Для `ou` требуются все поля, включая `theta`, `mu`, `sigma`.

## Проверка в коде

Этот файл является центральным источником числовых ограничений для приложения. При изменении диапазонов параметров обновляйте `specs/validation.md`, а также документацию и код, использующие эти правила.

- Бэкенд: используйте `specs/models.py` или аналогичную Pydantic-модель и ссылку на параметры из этого файла.
- Фронтенд: дублируйте те же предельные значения для лучшего UX, но воспринимайте `specs/validation.md` как единую правду.
