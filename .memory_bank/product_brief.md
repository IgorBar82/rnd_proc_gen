# Product Brief: Stochastic Process Visualizer (MVP)

## 1. Executive Summary  
Веб-приложение, позволяющее генерировать и визуализировать траектории случайных процессов. На первой итерации пользователь может выбрать один из двух процессов (Винеровский или Орнштейна–Уленбека), настроить его параметры и получить график одной реализации.

## 2. Целевая аудитория  
- Студенты и преподаватели (изучение стохастических процессов)  
- Аналитики данных для быстрой генерации примеров  
- Разработчики, нуждающиеся в демонстрации поведения процессов

## 3. Функциональные требования (MVP)

### 3.1 Выбор процесса  
Выпадающий список с двумя вариантами:  
- **Wiener process** (стандартное броуновское движение)  
- **Ornstein–Uhlenbeck process**  

### 3.2 Параметры процесса (пользователь может изменять)

#### Общие для обоих процессов
| Параметр | Смысл | Диапазон / ограничения |
|----------|-------|------------------------|
| `T`      | Время окончания | > 0, не более 10 |
| `N`      | Количество шагов дискретизации | целое, от 100 до 5000 |

#### Для Wiener process
- `X0` – начальное значение (допустимый диапазон: от -5 до 5)

#### Для Ornstein–Uhlenbeck process
| Параметр | Смысл | Диапазон |
|----------|-------|----------|
| `θ` (theta) | Скорость возврата к среднему | (0, 10] |
| `μ` (mu)    | Долгосрочное среднее | [-5, 5] |
| `σ` (sigma) | Волатильность | (0, 5] |
| `X0`        | Начальное значение | [-5, 5] |

### 3.3 Управление генерацией  
- Кнопка **«Generate trajectory»** – создаёт новую траекторию с текущими параметрами.  
- Кнопка **«Reset to defaults»** – возвращает все параметры (включая тип процесса) к исходным значениям и генерирует траекторию по умолчанию.

### 3.4 Визуализация  
- График **одной** траектории: время по горизонтали, значение процесса по вертикали.  
- Заголовок графика меняется в зависимости от выбранного процесса и его параметров.  
- Оси подписаны: `Time (t)` и `Process value X(t)`.

### 3.5 Экспорт данных  
- Кнопка **«Download CSV»** – сохраняет текущую траекторию в виде файла с колонками `time, value`.

## 4. Нефункциональные требования (качество работы)

### 4.1 Производительность  
Генерация траектории с максимальным `N = 5000` должна занимать не более 0.5 секунды на обычном ноутбуке или смартфоне.

### 4.2 Точность симуляции  
- Траектория Винеровского процесса должна выглядеть как непрерывное, но негладкое броуновское движение.  
- Траектория Орнштейна–Уленбека должна демонстрировать возврат к среднему `μ` при больших отклонениях.

### 4.3 Совместимость  
Приложение работает в актуальных версиях Chrome, Firefox, Safari, Edge. Интерфейс адаптируется под ширину экрана от 320 px до 1920 px.

### 4.4 Доступность  
Все элементы управления имеют подписи, воспринимаемые скринридерами. Цвета графика и текста контрастны (соответствие WCAG AA).

## 6. Критерии приёмки (с точки зрения продукта)

1. Пользователь может выбрать тип процесса – параметры на экране меняются соответственно.
2. При нажатии `Generate` строится график, визуально соответствующий выбранному процессу.
3. Изменение `N` меняет количество точек на графике (график становится более детальным или грубым).
4. После `Reset` все параметры возвращаются к значениям по умолчанию, график перерисовывается.
5. Кнопка `Download CSV` выгружает файл с корректными числовыми данными текущей траектории.
6. При вводе экстремальных значений (например, `T=0.01`, `N=5000`) приложение не ломается и выводит осмысленный график или сообщение об ошибке валидации.

## 7. Что НЕ входит в MVP

- Сравнение нескольких траекторий на одном графике
- Анимация построения (пошаговая отрисовка)
- Сохранение параметров между сессиями
- Выбор seed для воспроизводимости
- Бэкенд – вся логика на клиенте
- Другие типы процессов (геометрическое броуновское движение, процесс Коши и т.д.)

## 8. Метрики успеха MVP

- Время от загрузки страницы до первого полноценного графика ≤ 2 секунд.
- 95% попыток генерации завершаются без ошибок ввода (пользователь видит корректный график).
- Пользователь может объяснить, как параметры влияют на вид траектории, просто экспериментируя с интерфейсом (без чтения документации).
