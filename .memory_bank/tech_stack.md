# Tech Stack: Stochastic Process Visualizer (MVP)

## 1. Тип приложения
- **Веб-сервис** с REST API (опционально WebSocket для будущих расширений)
- Статический фронтенд (HTML, CSS, JS) без шага сборки
- Бэкенд выполняет генерацию траекторий и отдаёт данные в формате JSON

## 2. Бэкенд

### 2.1 Язык и версия
| Компонент | Версия | Обоснование |
|-----------|--------|-------------|
| Python | 3.11+ | Высокая производительность, богатая экосистема для научных вычислений |

### 2.2 Веб-фреймворк
| Технология | Версия | Обоснование |
|------------|--------|-------------|
| FastAPI | 0.100+ | Асинхронность, автоматическая генерация OpenAPI-документации, низкая задержка |

### 2.3 Генерация случайных процессов
| Библиотека | Назначение |
|------------|-------------|
| NumPy | 1.24+ | Эффективные векторные операции, генерация нормально распределённых случайных чисел, реализация методов Эйлера–Маруямы |

### 2.4 Запуск и сервер
| Инструмент | Назначение |
|------------|-------------|
| Uvicorn | Асинхронный WSGI-сервер для запуска FastAPI |
| Gunicorn (опционально для production) | Менеджер процессов (если потребуется многопроцессность) |

### 2.5 Управление зависимостями
| Инструмент | Назначение |
|------------|-------------|
| pip + requirements.txt | Простота, минимальная зависимость |
| или Poetry | Для более строгого управления версиями (на выбор команды) |

### 2.6 Линтинг и форматирование (бэкенд)
| Инструмент | Назначение |
|------------|-------------|
| Ruff | Быстрый линтер и форматтер, замена flake8/black |
| mypy | Статическая типизация (опционально) |

## 3. Фронтенд

### 3.1 Базовые технологии
| Технология | Версия | Примечание |
|------------|--------|------------|
| HTML5 | - | Структура страницы |
| CSS3 | - | Стили (адаптивная вёрстка через Flex/Grid) |
| JavaScript | ES2020+ | Чистый JS, без фреймворков, без шага сборки |

### 3.2 Визуализация графиков
| Библиотека | Версия | Способ подключения |
|------------|--------|--------------------|
| Plotly.js | 2.x | CDN (без сборки) |

### 3.3 HTTP-запросы
| API | Назначение |
|-----|-------------|
| Fetch API (встроенный) | Отправка POST-запросов с параметрами на бэкенд, получение JSON |

### 3.4 Структура фронтенда
- Один `index.html` (точка входа)
- Один `styles.css` (стили)
- Один `app.js` (вся клиентская логика: работа с DOM, валидация, вызов API, отрисовка графика)
- Все скрипты подключаются через `<script src="...">` без сборки

### 3.5 Адаптивность и доступность
- CSS Media Queries для трёх брейкпоинтов (мобильный, планшет, десктоп)
- Семантическая вёрстка (button, input, label) с `aria-*` атрибутами

## 4. API дизайн (для справки, без деталей реализации)

| Endpoint | Метод | Тело запроса (JSON) | Ответ |
|----------|-------|---------------------|--------|
| `/api/generate` | POST | `{ process_type, T, N, X0, theta?, mu?, sigma? }` | `{ time: [...], values: [...] }` |

- Статус коды: 200 (успех), 400 (ошибка валидации), 500 (внутренняя ошибка)
- При необходимости WebSocket — будущий `ws://` для потоковой генерации

## 5. Тестирование

### 5.1 Бэкенд
| Инструмент | Назначение |
|------------|-------------|
| pytest | Фреймворк для тестов |
| pytest-asyncio | Поддержка асинхронных тестов (FastAPI) |
| requests (или httpx) | Интеграционные тесты эндпоинтов |

### 5.2 Фронтенд
| Инструмент | Назначение |
|------------|-------------|
| Нет фреймворков – ручное тестирование в браузере | Для MVP допустимо, но может быть добавлен Vitest с jsdom (не нарушая требования "без сборки") – решение за коман-дой |

## 6. Хостинг и развёртывание

| Компонент | Платформа |
|-----------|-----------|
| Бэкенд | любой облачный хостинг, поддерживающий Python (Heroku, Render, DigitalOcean, AWS EC2) |
| Фронтенд | тот же сервер (статические файлы отдаются тем же FastAPI) или отдельный CDN (Netlify) |
| Рекомендация для MVP | Разместить бэкенд на Render.com, фронтенд – статические файлы внутри того же FastAPI для простоты |
