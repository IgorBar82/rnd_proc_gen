# Testing Strategy: Stochastic Process Visualizer

## 1. Цели и принципы
- Обеспечить корректность генерации траекторий случайных процессов.
- Гарантировать стабильную работу REST API и фронтенда.
- Выявлять регрессии при изменениях.
- Приоритет: **юнит-тесты на математику** > **интеграционные тесты API** > **ручное E2E**.

## 2. Уровни тестирования

### 2.1 Юнит-тесты (бэкенд)
- **Что тестируем**: 
  - Функции генерации Винеровского и Орнштейна–Уленбека.
  - Вспомогательные математические функции (Box–Muller, расчёт шага).
  - Валидаторы параметров (границы, типы).
- **Инструмент**: `pytest`
- **Требования к покрытию**: >80% для модулей `processes.py`, `validation.py`.
- **Пример теста**:
```python
def test_wiener_generation():
    T, N = 1.0, 100
    time, values = generate_wiener(T, N, X0=0.0)
    assert len(time) == N+1
    assert len(values) == N+1
    assert time[0] == 0.0
    assert time[-1] == T
    assert values[0] == 0.0
