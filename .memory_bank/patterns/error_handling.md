# Error Handling: Stochastic Process Visualizer

## 1. Общие принципы
- **Не падать** – любая ошибка должна быть обработана, приложение продолжает работать (показывает сообщение пользователю и/или логирует).
- **Безопасность** – не раскрывать внутренние детали реализации клиенту (стектрейсы, пути к файлам, версии библиотек).
- **Пользовательские сообщения** – понятные, на русском или английском (в зависимости от целевой аудитории), без технического жаргона.
- **Единый формат ошибок** – для API (JSON) и для фронтенда (отображение в UI).
